# 2026-11-06

## 修复战报体力消耗日志不一致 + 新增 --seed

- `src/battle_engine.py` `_process_single_attack`：原代码在扣减 SP 的行与写日志的行各调用一次 `attacker.attack_sp_cost()`（270 / 295 行）；该函数依赖 `sp_percent`/`hp_percent`，第二次计算时 SP 已扣减，导致战报数值失真。改为在扣减前只算一次存入 `attack_cost`，`consume_sp` 与日志复用同一值。seed=42 单场 180 条攻击日志不符数从 4 降为 0。
- `main.py`：新增 `--seed`（`type=int`, 默认 None，不设时完全不干预随机状态，保持原行为）；新增 `apply_seed(seed, battle_index)`，按场次 `seed + i` 派生，保证「同 seed 同 n 完全可复现」且「前 k 场与 -n k 一致」；单场分支用 index 0；启动时打印「随机种子: N」。
- `tests/test_combat.py`：新增 5 个测试（日志体力消耗 == 实际扣减、apply_seed 确定性 / 按场次区分 / None 不动随机状态、CLI 同 seed 输出字节一致），测试数 8 → 13。
- 验证：`python tests/test_combat.py -v` 13/13 OK（1.5s）；`main.py --seed 2026 -n 5` 两次输出 `cmp` 完全一致；不带 seed 时输出无种子行且仍随机（平均回合数不同）。
- 约定：本项目纯标准库、无第三方依赖；CLI 属 Windows 环境，输出需 UTF-8（main.py 中 `reconfigure` 必须在 parse_args 之前）。
